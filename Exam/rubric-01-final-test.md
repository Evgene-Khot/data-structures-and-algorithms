# Рубрика-01 (Exam). Экзаменационный письменный тест

10-балльная шкала; балл переводится в БРС с коэффициентом 3,0 (до 30 баллов за экзамен). Итоговая оценка выставляется по сумме баллов текущего контроля и экзамена (см. [`README.md`](../README.md#4-итоговая-оценка)).

| Уровень | Описание |
| --- | --- |
| **10** | Глубокое усвоение материала всех разделов; теоретическая часть без ошибок; практическая задача решена корректно, сложность решения оценена и обоснована. |
| **8** | Твёрдые знания; несущественные неточности в теоретической части; практическая задача решена, мелкие недочёты исправлены при собеседовании. |
| **6** | Освоен основной материал; допущены неточности и нарушения логической последовательности; практическая задача решена частично, базовый случай работает. |
| **4** | Пороговый уровень: существенные пробелы по отдельным разделам; практическая задача решена по образцу с ошибками. |
| **0–3** | Незнание основной части материала; практическая задача не решена или решение не объяснено. |

## Критерии (вклад в итоговый балл)

| Критерий | Доля |
| --- | --- |
| Теоретическая часть (полнота и корректность ответов по разделам 1–4) | 50 % |
| Практическая часть: корректность реализации | 30 % |
| Практическая часть: оценка сложности и обоснование выбора | 20 % |

## Связь с БРС

Балл рубрики × 3,0 → до 30 баллов БРС, которые суммируются с баллами текущего контроля (до 74); итог — не более 100 баллов.

- Балл рубрики **не ниже 4** (не менее 12 баллов БРС) — экзамен сдан, оценка выставляется по сумме баллов.
- Балл рубрики **0–3** — незнание основной части программного материала: «неудовлетворительно» независимо от баллов текущего контроля.

| Баллы БРС | Оценка | Требования к результатам освоения дисциплины (ФОС) | Уровень сформированности компетенций |
| --- | --- | --- | --- |
| 68–100 | Отлично (5) | Глубокое усвоение программного материала, логически стройное его изложение, умение применить теоретические знания для решения задач | высокий |
| 58–67 | Хорошо (4) | Твёрдые знания программного материала, допустимы несущественные неточности в ответе на вопросы, правильное применение теоретических положений при решении задач | хороший |
| 47–57 | Удовлетворительно (3) | Знание только основного материала, допустимы неточности в ответе на вопрос, недостаточно правильные формулировки, нарушение логической последовательности в изложении теоретического материала | достаточный |
| Менее 47 | Неудовлетворительно (2) | Незнание основной части программного материала, неумение сформулировать правильные ответы на вопросы экзаменационного билета | недостаточный |

Сумма баллов округляется до целого по правилам математического округления.
